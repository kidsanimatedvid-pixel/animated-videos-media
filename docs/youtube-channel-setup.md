## Settings checklist
1. Create the channel on youtube.com while signed in as kidsanimatedvid@gmail.com (profile picture → Create a channel), using the name and handle above.
2. Customise channel → Branding: upload `avatar.png` as the picture and `banner.png` as the banner.
3. Customise channel → Basic info: paste the description.
4. YouTube Studio → Settings → Channel → Advanced settings → Audience: **Yes, set this channel as made for kids**.
5. Same page: country = your real country of residence.
6. Settings → Upload defaults: category Education, video language Arabic, title language Arabic, audience Made for Kids.
7. Create two playlists: حكايات سُهَيْل and تعلَّم مع سُهَيْل.
8. Connect the channel to vidIQ (Claude sends the sign-in link; tick every permission box).
